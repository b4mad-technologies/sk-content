# Playtest Mini

A two-room example with two fighter heroes, a door, a chest with a potion,
and a longsword. The door is an open map annotation. The example uses the
SRD bundle.

The original room and item rows were authored using Spellkave's AUTHOR
tools. Ada, Bram and the Wield action were adapted from the Spellkave
player test fixture. The committed `fixtures/manifest.toml` is the editable
source. Run `pnpm test` from the repository root to check it with the SRD.

See the [repository credits](../../NOTICE.md) for the SRD attribution.
